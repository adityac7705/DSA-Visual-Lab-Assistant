BFS Traversal

What is BFS (Breadth-First Search)?

Breadth-First Search (BFS) is a fundamental graph traversal algorithm used to explore nodes in a graph level by level. Starting from a chosen source node, BFS first visits all its immediate neighbors, then moves on to the neighbors’ neighbors, and continues this process until all reachable nodes are explored. This method uses a queue data structure to keep track of nodes to visit next, ensuring that nodes closer to the source are explored before those further away. BFS is commonly used in applications such as finding the shortest path in unweighted graphs, web crawling, social network analysis, and solving puzzles or games that require level-wise exploration. The time complexity of BFS is O(V + E) for a graph represented using an adjacency list, since each vertex and edge is visited once, and O(V²) for an adjacency matrix, where each vertex checks all possible edges. The space complexity is O(V) due to the queue and visited list used to track explored nodes.


Steps of BFS

  • Step 1: Choose a start node and mark it visited.
  • Step 2: Enqueue the start node into a queue.
  • Step 3: While the queue is not empty, dequeue a node and visit it.
  • Step 4: Enqueue all unvisited neighbors of the node into the queue.
  • Step 5: Repeat until the queue is empty — BFS is complete.
