DFS Traversal

What is DFS (Depth-First Search)?

Depth-First Search (DFS) is a graph traversal algorithm that explores as far as possible along each branch before backtracking. Starting from a source node, DFS moves to an unvisited neighbor, then continues deeper along that path until it reaches a node with no unvisited neighbors, at which point it backtracks to explore other paths. DFS is typically implemented using a stack data structure or recursion. It is widely used in applications like detecting cycles in graphs, topological sorting, solving mazes or puzzles, and finding connected components in a graph. The time complexity of DFS is O(V + E) for a graph represented with an adjacency list, since every vertex and edge is visited once, and O(V²) for an adjacency matrix, where each vertex examines all possible edges. The space complexity is O(V) due to the recursion stack or explicit stack and the visited list.


Steps of DFS

  • Step 1: Choose a start node and mark it visited.
  • Step 2: Explore each unvisited neighbor deeply before moving to others.
  • Step 3: Use a stack (or recursion) to backtrack when needed.
  • Step 4: Repeat until all nodes are visited.
  • Step 5: DFS completes when there are no unvisited nodes left.
