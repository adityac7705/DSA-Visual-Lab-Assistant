Merge Sort

What is Merge Sort?

Merge Sort is a classic divide-and-conquer sorting algorithm. It works by recursively dividing an unsorted array into two halves until each subarray contains only a single element, which is inherently sorted. After the division, the algorithm merges these smaller arrays step by step to produce new sorted subarrays, gradually combining them until the entire array is sorted. The key idea is that merging two sorted arrays is efficient and ensures the overall array remains sorted. This approach makes Merge Sort stable, meaning it preserves the relative order of equal elements, which can be important in certain applications.


The algorithm has a consistent time complexity of O(nlogn) for best, average, and worst cases, making it highly efficient for large datasets compared to simpler algorithms like Bubble Sort. Its space complexity is O(n) due to the auxiliary arrays used during merging. Merge Sort is widely used in applications where stability and predictable performance are important. Despite requiring extra memory, its predictable efficiency and simplicity of concept make it a foundational algorithm in computer science and a standard choice for sorting large datasets.


Steps to solve Merge Sort

  • Step 1: Check if the array has one or zero elements — if yes, it’s already sorted.
  • Step 2: Find the middle index of the array.
  • Step 3: Split the array into two halves: left and right.
  • Step 4: Recursively apply merge sort to the left half.
  • Step 5: Recursively apply merge sort to the right half.
  • Step 6: Merge the two sorted halves by comparing elements and arranging them in order.
  • Step 7: Return the fully merged and sorted array.
